Plot Armor Index

How likely is a fictional character to die? This scores on-screen characters from 38 franchises on the attributes a writer actually controls — who they are, how prominent they are, and how central they are to the story.

What drives this model

How much each attribute actually varies the prediction across the characters below — not how much it matters for any one of them. Measured as the spread of each attribute's contribution to the log-odds, so a feature with many rare categories doesn't outrank a common one just for having more of them.

Built for “A Needle in a Data Haystack”. The model is a logistic regression over user-selectable attributes only; the project's full model uses many more features and scores higher. Predictions describe patterns in how these stories were written — not what any character deserves.
